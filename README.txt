蟹谷のどかと学ぶ CMOSアナログ回路
オフラインHTMLノベルゲーム v1.0

起動
1. ZIPをすべて展開します。
2. 展開したnodoka_gameフォルダのindex.htmlをブラウザで開きます。
3. はじめからを押して名前を入力します。
画像だけ移動せず、フォルダ全体を保ってください。
スマートフォンでは、展開したHTMLの実行に対応するブラウザやローカルHTML表示アプリが必要です。ファイルアプリのプレビューではJavaScriptが動かない場合があります。静的Webサーバーでもそのまま動作します。

操作
つづきを読む、会話文のクリック、Space、Enter：文章を進める
文字送り中の操作：全文を表示
選択肢：クリックまたは数字キー1〜4
メニュー：セーブ、ロード、設定、ステータス、保存データの書き出し
ログ：過去の会話を読む
学習メモ：読んだ章の技術説明を確認
既読スキップ：読んだ台詞だけを進め、未読と選択肢で停止

収録内容
プロローグ、第1〜17章、最終章、補習、関係修復、4種類の結末。
生成AIによる10表情と7背景。
オリジナルの音符データをWeb Audio APIで合成するBGMと効果音。
プレイ時間は読む速さ、補習、メモの利用によって変わります。

保存
進行中は自動保存します。手動枠は3つです。
保存先はブラウザ内です。ファイルの移動、別のブラウザ、プライベートモード、端末の設定などによって保存が引き継がれない場合があります。
確実に持ち運ぶにはメニューのデータ管理からJSONを書き出してください。
全データ削除は確認画面のあとに実行されます。

音
開始または再開操作後に音が有効になります。
BGMと効果音は別々に調整でき、すべてミュートも可能です。
タブが非表示になると音を停止します。
音声の台詞は収録していません。

学習上の前提
MOSの説明は主に長チャネル・強反転・小信号の簡単な近似です。
適用条件は本文と学習メモに記載しています。
SPICE解析メモは学習用の架空データであり、このゲーム内でSPICEを実行していません。
実際のIC設計ではプロセスモデル、構成、電源・温度・負荷、寄生素子などを確認してください。

最終課題
電源±1.5 V、Av 60 dB以上、単位利得周波数45 MHz以上。
PM目標60°、ゲーム内判定範囲55〜70°。
SR両方向7 V/μs以上、CL 1.1 pF、電力1.1 mW以下。

編集
topics.js：17章の文章、問題、雑談
 game.js：プロローグ、最終章、分岐、セーブ、UI
 audio.js：音符、音色、音量包絡
 style.css：画面レイアウト
 assets：生成した背景・立ち絵
外部ライブラリ、CDN、ネット接続は必要ありません。

画像制作
添付された女の子を参考に、組み込み画像生成機能で新規立ち絵と表情差分を制作。
背景も同機能で生成。生成後はWebPへ変換して同梱。
背景には回路図・数式・波形・人物を描かない方針です。
プロンプトはASSET_PROMPTS.txtに記録しています。
